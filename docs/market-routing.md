# 거래 시장과 심볼 보정

2026-09-22. 시장 시간은 ETF 자산유형과 분리해 판정한다. `symbol_market.get_trading_market()`은 검증된 심볼의 `.KS`/`.KQ` 접미사를 한국, `-USD`/`-USDT`를 크립토, 그 밖의 기존 지원 심볼을 미국으로 분류한다. `config`도 이 함수를 노출하며 시장별 목록, 트리거 알림 시간과 `market_dates`의 날짜 기준이 같은 규칙을 사용한다.

## 한국 ETF 알림

한국 ETF는 한국 활성 시간에 트리거 알림을 보내고 한국 보고서 범위에 들어간다. 기존 `get_market_type()`의 ETF 분류와 `get_atr_multiple()`의 ETF 배수는 유지한다. 시장을 고치기 위해 ATR 분류 순서를 바꾸지 않는다. 같은 입력의 ATR·Chandelier 수치는 바뀌지 않는다.

`market_hours.is_market_active("ETF", ...)`의 기존 미국 시간 별칭은 호환성을 위해 유지한다. 모니터는 이 별칭 대신 실제 거래 시장을 전달한다. 한국 08:00–20:00, 미국 04:00–20:00의 기존 활성 범위, 지역 주말 판정, 크립토 상시 활성, 실행 창·디스패처 스케줄은 그대로다. 이 시간 범위는 기존 앱 정책을 설명하며 실제 거래소 일정 검증을 뜻하지 않는다.

## 접미사가 없는 숫자 코드

숫자 코드만으로 시장을 정하지 않는다. Drive 입력에서 `구분=한국/코스닥`이 명시되면 기존 접미사 부착과 6자리 zero-padding을 유지한다. 해당 두 구분의 `991.0` 같은 정수형 소수 표기는 끝의 0인 소수부만 제거해 `000991.KS`/`000991.KQ`로 복원한다. 이미 명시된 접미사는 구분보다 우선하며 그대로 둔다.

`구분=ETF/미국/미지정` 등에 남은 접미사 없는 정수 코드와 `.0` 형태는 설정 오류다. ETF라는 정보만으로 한국 거래소를 추정하지 않는다. `STOCK_LIST`는 완성된 심볼을 받으므로 그룹 이름과 무관하게 같은 숫자 입력을 거절한다. 예를 들어 가상 코드 `999991`은 실제 입력자가 시장을 확인해 명시적 접미사를 적어야 한다.

잘못된 행 하나를 건너뛰어 부분 감시로 시작하지 않는다. 기존 `PORTFOLIO_SOURCE=invalid` 경로로 전체 설정을 거절하고 fallback으로 바꾸지 않는다. 로그의 오류는 고정된 코드나 예외 타입만 사용하며 입력값·이름·계좌를 출력하지 않는다. 실제 사용자 입력이나 보유 정보는 이번 변경에서 조회·수정하지 않았다.

## 크립토 검색 보완

최초 요청 심볼의 history가 비었을 때만 기존 검색 보완을 시도한다. 검색 결과에서 같은 통화 접미사와 `CRYPTOCURRENCY` 유형을 가진 문자열 심볼만 검토한다.

1. 정확한 요청 심볼이 있으면 결과 순서와 무관하게 우선한다. 그 심볼의 데이터가 비었다고 다른 숫자 변형으로 바꾸지 않는다.
2. 정확한 심볼이 없으면 요청 base 뒤에 ASCII 숫자가 붙은 후보만 모아 동일 심볼의 중복을 제거한다.
3. 서로 다른 후보가 하나이고 응답이 검색 개수 제한에 도달하지 않았을 때만 대체 조회를 한 번 한다. 후보가 여러 개이거나 결과가 제한에 걸렸을 수 있으면 자동 보정을 보류한다.
4. 심볼·유형 필드의 공백이나 제어문자를 포함해 잘못된 응답은 전체 보류한다. 그런 행을 무시해 정확한 심볼이나 다른 후보를 놓치지 않는다. 검색 실패도 임의 심볼 선택으로 보완하지 않는다. 원래 포트폴리오·상태의 심볼 키와 조회 기간·조정가 정책은 유지한다.

검색 응답 안의 유일함은 전 세계 자산의 동일성이나 유일성을 입증하지 않는다. 유일한 숫자 변형을 사용하는 기존 보완은 더 제한된 형태로 남으며, 소유자가 확인한 canonical 심볼을 입력에 고정하는 절차는 별도 잔여다. 실제 검색 API나 시세를 호출해 자산의 동일성을 확인하지 않았다.

## 검증

검사는 `python scripts/run_offline_tests.py`로 코드 사본·합성 입력·mock 응답에서 수행한다. 한국 ETF 장중·장외·주말, 미국 ETF DST와 UTC 날짜 경계, 크립토 상시 활성, 보고서의 시장별 포함 여부, 별도 ETF 배수를 주입한 ATR 수치 보존, 숫자 입력 거절·복원, 크립토 정확 일치·모호성·검색 제한·대체 조회 횟수를 검사한다.

시장 시간의 실거래소 동기화, 휴장일 달력, 전체 심볼 문법 및 존재 여부 검증, 자산별 수동 확정 매핑, 실제 포트폴리오 정정은 이번 범위 밖이다.
